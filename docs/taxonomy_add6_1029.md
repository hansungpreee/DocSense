## 테스트 기대값을 바꾼 곳 (`tests/test_engine.py`, 8곳)

소분류 개수(19 → 25)와 `add_minor`가 발급하는 다음 번호가 바뀝니다: FIN-10 → **FIN-11**, HR-04 → **HR-05**, SAL-03 → **SAL-06**(LEG-03은 그대로). 새 코드가 가안이라 코드가 바뀌면 이 기대값도 다시 맞춰야 합니다. 테스트 파일은 백엔드 1 담당이라 알려야 합니다.
